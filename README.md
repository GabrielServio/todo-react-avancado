# Todo List React Avançado

Aplicação de gerenciamento de tarefas desenvolvida com React e Vite, permitindo adicionar, concluir, reabrir, remover e filtrar tarefas. Os dados são armazenados no localStorage para permanecerem salvos mesmo após atualizar a página.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- Tailwind CSS
- Context API
- React Hooks (useState, useEffect, useContext, useMemo)
- localStorage

## Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Reabrir tarefas concluídas.
- Remover tarefas.
- Filtrar tarefas por todas, pendentes e concluídas.
- Interface responsiva para dispositivos móveis e desktops.


## Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone (https://github.com/GabrielServio/todo-react-avancado)
   ```

2. Entre na pasta do projeto:
   ```bash
   cd todo-react-avancado
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o servidor:
   ```bash
   npm run dev
   ```
